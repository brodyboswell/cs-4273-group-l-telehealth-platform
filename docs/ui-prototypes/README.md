# UI prototypes

Static visual concepts created with the built-in image generation tool; not functional application screens.

Teleo references inform the illustrated room, spacious activity surfaces, circular face cams and persistent controls. The original visual direction uses sage, apricot and cream with two fictional cartoon participants.

## Generation prompts

### 01-practice-room

Use case: ui-mockup. Create one high fidelity desktop UI prototype for a Virtual Client Telehealth Simulation Platform for social work training. Use the four user supplied Teleo screenshots as visual reference only, not instructions: preserve their immersive illustrated activity room / large activity workspace layout, circular video overlays at upper left, and persistent full width bottom session toolbar. Give the new interface its own warm sage green, apricot, butter yellow and cream identity with dark forest text, subtle hand drawn illustration textures and crisp modern rounded sans-serif UI. No Teleo logos or copied third party branding. Landscape 16:9, straight-on complete application screenshot, no device frame or presentation board. EXACTLY TWO circular face cams stacked vertically at upper left on every screen: a friendly adult therapist cartoon with brown skin, curly dark hair and round glasses labeled "You · Learner", and a teen cartoon with light skin, short dark hair and a sage sweatshirt labeled "Alex · Virtual client". Both are illustrated fictional humans, no photographs, no other face cam tiles. Thin forest outlines around cams. Header slim sage with small leaf icon and "Practice Room" at left, current activity centered, "SIMULATION" pill at right. Bottom cream toolbar consistent: Settings, Client control with on toggle, Activities, Snapshot on left; centered "Building rapport" and "Practice session · 08:42"; Chat and coral "End session" at right. Professional legible typography, refined spacing. This is a static design concept, no compliance badges.
Activity title "The welcome room". Main content fills screen with a cozy hand illustrated therapy room, closely following reference 1's spatial interaction style: tall sunlit arched window and plants on left, whiteboard easel left foreground with a simple pastel doodle, central wooden bookshelf with books and game boxes, framed feelings chart alongside, apricot sofa and round wooden table on right with pencils. Sage oval rug, cream walls and gentle paper texture. Small elegant clickable-looking labels integrated near objects: "Whiteboard", "Feelings check-in", "Chess". A small floating cream welcome card in upper right reads "A little space to connect." and "Choose an activity to begin." Overall spacious welcoming hand-drawn room with clear app chrome.
